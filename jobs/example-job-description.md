# Example Job Description - Full-Stack Software Engineer

## Responsibilities

- Build responsive web applications using React and TypeScript.
- Develop REST APIs using Node.js.
- Work with a document database.
- Debug application issues and write unit tests.
- Participate in Agile ceremonies and code reviews.

## Requirements

- One or more years of software development experience.
- React and TypeScript experience.
- Node.js and REST API experience.
- Database experience.

## Analysis prompts

When tailoring, extract required technologies, responsibilities, preferred skills, experience requirements, and keywords. Map each requirement to evidence in `knowledge/`, then record unsupported requirements separately.
